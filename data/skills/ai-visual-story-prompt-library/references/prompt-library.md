# 提示词库

以下模板中的 `【】` 是可替换变量。输出给用户时，优先把其已提供的信息填入；未提供时保留变量并附一行“可替换项”。

## 1. 万能公式｜生图结构

**适用索引：** `万能公式`、`生图结构`、`生图提示词`

**主提示词骨架**

```text
【画幅】，【视觉风格】；【构图与镜头：景别、角度、主体位置、留白】。主体是【身份/物体】，具有【外貌或结构锚点】；身穿/呈现【服装、材质、颜色、配饰】；正在【动作、姿态、表情、视线】。置于【时间、地点、环境和关键道具】；【主光方向、色温、明暗关系和氛围】。重点呈现【需要看清的细节】；【渲染/摄影质感】；画面干净、层次清楚、主体不被遮挡。
```

**避免项骨架**

```text
低清晰度、主体跑偏、多人/重复主体、五官或结构变形、额外肢体、遮挡主体、过度磨皮、塑料质感、文字乱码、水印、Logo、过曝、杂乱背景。
```

默认不堆砌“8K、电影感、超清”等泛化词。用户要写实人物时补充真实肤质、自然毛孔、自然高光；用户要动画或国漫时改为线条、厚涂、材质与色彩逻辑。

## 2. 角色资产｜三视图与人设卡

**适用索引：** `角色资产`、`角色卡`、`三视图`、`人设卡`

**完整提示词**

```text
横版 16:9，专业角色资产设定档案，白色或极浅色高级背景，清晰模块化排版，预留文字区供后期排版，不生成大段中文。角色为【姓名/编号】，【年龄段】的【身份】，整体风格【风格主题】；主配色【主色1、主色2、辅助色】，以【点缀色】少量强调。

人物母版固定：脸型【】，五官【】，肤色【】，身形比例【】，发型与发色【】，妆容【】，气质【】。服装固定为【上衣】、【下装/裙装】、【鞋袜】，配饰为【发饰、耳饰、项链、手链、徽章】；同一版面所有视图的脸、发型、服装、配饰、体型和年龄感必须完全一致。

版面布局：左侧为正脸大头像与半身质感特写；右侧为正面、3/4 侧面、背面全身标准三视图，统一站姿、机位、焦段和白底棚拍光线，完整展示头顶至鞋底；周边放置 6 个统一脸型的表情头像，依次为平静、微笑、放松、专注、惊讶、俏皮；底部拆解服装、鞋履、发饰、首饰、面料纹理、肤质与配色卡。柔和侧主光、细腻轮廓光、真实皮肤与布料材质、规整信息层级、游戏角色设定集质感。
```

**必配避免项**

```text
换脸、五官漂移、不同发型、服装变化、比例失真、缺失背面、裁切脚部、重复人物、额外手指、畸形肢体、图中文字乱码、水印、复杂花哨边框。
```

**图像样式要点：** 参考图常用“左大特写＋右三视图＋表情行＋服饰拆解＋色板”的横版资产卡。此布局比单张人像更适合后续做 AI 漫剧、分镜和图生视频。

## 3. 国风女主｜六大服饰体系

**适用索引：** `古风女主`、`古装美人`、`仙侠`、`宫廷`、`异域`、`江湖`、`妖族`、`敦煌`

先输出一个固定人物母版，再按风格替换包生成角色提示词。默认以成年人为原型，不写未成年人性感化内容。

**人物母版**

```text
【年龄段】东方女性，鹅蛋脸，比例协调的东方五官，【眼型、眉形、鼻梁、唇色】，自然通透肤质与细微皮肤纹理，黑色【发型】，气质【】，正面平视镜头，半身或全身定妆照，人物居中、面部无遮挡、真实电影摄影质感。
```

| 索引 | 服装与饰品 | 色彩与场景 |

```text
东方古风女性角色资产设定图，【人物母版】；采用【六大服饰体系中的一种】服饰体系，具体为【服装、发饰、饰品、手持物】；主色为【】，环境为【】，光线为【】。输出正面、3/4 侧面、背面三视图与面部近景，角色身份、发型、服饰和配色在所有视图中保持一致；【画幅】，国风电影概念设计，材质精细而不过度堆饰。
```

## 4. 星座角色图鉴｜人格差异化女主库

**适用索引：** `星座角色`、`女主库`、`角色图鉴`

用户指定星座时，以星座性格为“叙事人格”而非命理判断。每位角色至少区分：主色、轮廓、服装、发饰、动作、表情、环境纹样六项。

```text
横版 16:9 少女角色资产图鉴，主题【星座/人格原型】，角色为【姓名】，成年东方女性，【人格关键词】。以【主色】和【辅助色】建立鲜明识别，服装为【款式与材质】，饰品为【】，动作与表情为【】，背景装饰为【星座符号/纹样】。左侧高质量头像与半身特写，右侧正面、侧面、背面三视图，下方为 6 个表情、服装与配饰拆解、配色板；同一角色全部视图面孔、发型、服装、比例一致，精致偶像官方设定集风格，文字区域留空后期添加。
```

可用人格起点：白羊=热烈勇敢、狮子=明亮自信、天秤=优雅平衡、天蝎=神秘冷感、摩羯=清醒坚韧、双鱼=梦幻温柔。用户要求整套图鉴时，先输出 12 个角色差异矩阵，再逐个生成。

## 5. 仙侠阵法｜战斗视觉

**适用索引：** `阵法`、`仙侠战斗`、`玄幻分镜`

```text
【画幅】东方玄幻仙侠战斗概念图，场景为【地点】，主角【身份与固定外观】立于【阵法名称】中央；阵法由【几何结构/符文/武器/五行元素】构成，能量以【颜色、粒子、流向】从【起点】汇聚到【终点】。角色执行【明确动作】，衣袂、头发、碎石和烟尘因【风向/冲击】产生连续反应；【镜头景别、机位、运动趋势】，主光来自【月光/火光/阵法光】，环境保留【材质与空间细节】，史诗但画面层次清晰，禁止无意义的能量乱飞。
```

用户需要视频时，先把阵法拆成“蓄势—启动—扩张—收束”四个状态，再交接到视频提示词流程。

## 6. 漫剧流程｜原创剧本到分镜

**适用索引：** `漫剧流程`、`剧本转漫剧`、`分镜`、`短剧`

按以下顺序输出，不跳过资产阶段。

**A. 原创故事框架**

```text
请设计一部适合视觉化生成的【题材】原创 AI 短剧。要求前 3 秒有强冲突；主角有明确身份反差与核心目标；重要配角与主角存在利益冲突或隐藏关系；植入可视化线索【信物/场景/天气/道具】。输出：世界观、人物表、核心矛盾、前三集梗概、每集结尾钩子、视觉风格关键词。不得改编未获授权的小说或影视片段。
```

**B. 角色与场景资产提取**

```text
请分析以下原创剧本，按“人物资产”和“场景资产”分别编号输出可用于 AI 绘画的中文提示词。人物资产必须包含姓名、年龄段、身份、性格、外貌锚点、发型、服装、材质、配饰、标准三视图与一致性约束；场景资产必须包含时间、地点、空间结构、关键道具、材质、主光/辅光/环境光、镜头视角，并默认不出现人物。先输出资产清单，再输出每项完整提示词。
```

**C. 分镜脚本**

```text
请将以下原创剧情改写为专业分镜头脚本。每段总时长不超过 15 秒，每段 4–5 个镜头，用 [起止时间] 标注；为每个镜头写明景别、机位、构图、人物动作、表情、道具交互、环境变化、镜头运动和台词。高潮使用能服务叙事的特写与推镜；动作场面写清起因、受力、碰撞、反馈和收势。镜头之间保持人物身份、服装、道具、空间方向与光线连续。结尾附上本段的画面风格与“避免项”。
```

## 7. 视频｜图生视频与 H3 交接

**适用索引：** `视频`、`H3`、`图生视频`、`首尾帧`

收集或默认以下创作单：模式（T2V/I2V/首尾帧/多参考）、时长、画幅、参考素材职责、必须保持的锚点、主要动作、情绪、场景、运镜、灯光、对白、环境声、配乐、避免项。

当用户明确使用 MiniMax H3 时，必须读取并执行 `minimax-h3-prompt` 技能；将本技能产出的角色母版、场景资产和分镜作为其输入。若该技能不可用，按以下简化格式生成英文提示词：

```text
integrated_multimodal_description: [Shot 1] 【首帧构图、身份锚点、场景、动作起点、运镜、光线与同步声音】. [Shot 2] At 00:【切点】, 【动作连续发展与结果】.

overall_soundscape: 【连续环境声、动作声与非语言人声】.

non_diegetic_music: 【配器、节奏和动态；不需要则 N/A】.
```

## 8. 办公交付｜海报、PPT 与 3D 城市

**适用索引：** `海报`、`PPT美化`、`3D城市`、`办公交付`

**可编辑海报**

```text
我将提供【方案/品牌资料/Logo/视觉参考/文案】。请据此完成【物料清单】；明确每项尺寸、线上或印刷用途、受众和视觉调性。文字、图标和主体视觉分别产出为可编辑图层或独立透明底素材；同时交付成图与可编辑源文件。信息不足时只询问影响成品的缺口；交付前自行检查文字可读性、边距、比例、日期替换和印刷安全区。
```

**PPT 美化**

```text
请基于我上传的 PPT 与 PDF 预览，保留全部原始事实、关键数字和页序，按【受众/使用场景】重做视觉层级、网格排版、配色、渐变、图表和素材，保持【品牌/原有风格】。输出可编辑 PPTX，并逐页检查内容未遗漏、数据未被遮挡、封面/数据页/品牌页/末页风格一致。
```

**Three.js 城市场景**

```text
请参考我提供的城市案例，使用 Three.js 创建【城市】的可交互 3D 场景，包含【地标、地形/海湾、关键元素】；支持旋转、缩放、昼夜切换和自动巡游。交付可在浏览器打开的 HTML、完整源码和简明使用说明；完成后自行打开验证画面、交互与资源加载均正常。
```
