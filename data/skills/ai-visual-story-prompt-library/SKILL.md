# AI 视觉叙事提示词库

将用户输入的索引词识别为下列类别，并读取 [提示词库](references/prompt-library.md) 中对应章节，输出可直接复制使用的提示词。可接受 `$ai-visual-story-prompt-library 索引：角色资产`、`索引：古风女主` 或自然语言形式。

## 索引路由

| 索引词（可并用） | 生成内容 |
| --- | --- |
| `万能公式`、`生图结构`、`生图提示词` | 结构化文生图提示词：风格、构图、主体、动作、场景、光影、细节、质量与避免项。 |
| `角色资产`、`角色卡`、`三视图`、`人设卡` | 横版角色资产设定图，含一致性锚点、三视图、表情、服饰与配饰拆解。 |
| `古风女主`、`古装美人`、`仙侠`、`宫廷`、`异域`、`江湖`、`妖族`、`敦煌` | 以指定的国风服饰体系生成可连续使用的人物母版与角色提示词。 |
| `星座角色`、`女主库`、`角色图鉴` | 按人格原型批量生成角色资产图鉴，强调每个角色的色彩、服饰和动作差异。 |
| `阵法`、`仙侠战斗`、`玄幻分镜` | 生成仙侠阵法概念图、战斗定格帧或短镜头的可视化提示词。 |
| `漫剧流程`、`剧本转漫剧`、`分镜`、`短剧` | 依次产出原创剧本框架、角色/场景资产、分镜脚本与镜头提示词。 |
| `视频`、`H3`、`图生视频`、`首尾帧` | 输出视频创作单并生成视频提示词；MiniMax H3 请求优先交由可用的 `minimax-h3-prompt` 技能执行。 |
| `海报`、`PPT美化`、`3D城市`、`办公交付` | 生成可编辑海报、PPT 美化或 Three.js 场景的任务提示词与验收标准。 |

若索引词只给出风格而未给出角色、用途、画幅或工具，直接采用参考章节的默认变量并在输出末尾列出可替换项；仅在缺失信息会使产物完全不同（例如用户同时要求首帧与尾帧、但未说明两图职责）时提问。

## 输出方式

1. 先用一行说明识别到的索引和采用的默认值。
2. 给出一份完整、可复制的中文提示词；需要避免项时单列“避免项”。
3. 角色、场景或镜头为多个时，按编号分别输出，避免把多位角色混进同一张图。
4. 用户要求“批量”时，默认一次输出 3 个角色或 6 个镜头；要求更大批次时先给出角色矩阵，再按批次生成完整提示词。
5. 保留用户明确指定的名称、服饰、对白、产品文字和构图；不要把图像中难以稳定生成的长段中文强行写入画面，改为“预留文字区/后期排版”。

## 质量规则

- 每条生图提示词依次明确：主体身份、外貌或物体锚点、服装/材质、姿态或动作、构图镜头、场景、光线、风格；只保留真正影响画面的质量词。
- 同一角色跨图复用完整的“人物母版”；仅替换服饰、场景或情绪等变化项。需要漫剧连续性时，先生成并确认母版，再制作分镜和视频。
- 三视图、表情、服饰拆解和配色板必须在同一张资产图中共享相同脸型、发型、服装与比例；明确禁止换脸、服装漂移、额外肢体和文字水印。
- 分镜将剧情拆成可在短时长内完成的连续动作，写清景别、机位、运动、表演和可见的因果关系；对白仅在用户提供或明确要求时加入。
- 使用原创或已获授权的剧本、形象和品牌素材；不把未授权小说片段或他人的角色设定直接改造成成片。
- 对 `H3`、`视频` 请求，优先使用 `minimax-h3-prompt` 技能的模式匹配和三字段输出规范；本技能只负责把角色资产、镜头和场景信息交接过去。

## 来源范围

本技能由 14 个用户提供的公众号链接整理而成，其中 13 篇已读取正文与图像样式，1 篇受公众号验证码限制未能读取。按文章的主题、模板结构与可见图像样式归纳而非逐字复制。需要查看来源、图片观察或未读取链接时，阅读 [来源审计表](references/source-audit.md)。
